> **AGENT 1** is an all-terrain, fully autonomous Unmanned Ground Vehicle (UGV) equipped with a multi-DOF precision robotic arm, stereoscopic obstacle sensing, and an onboard Edge-AI computer vision processing system. Developed by the **Blueprinters Team** (Faculty of Artificial Intelligence, Horus University in Egypt) for international competitions and real-world field deployment.

---

## 📌 Highlights

- 🚜 **All-Terrain High-Torque Drivetrain**: Multi-wheel skid-steer architecture engineered for desert, gravel, and rubble navigation.
- 🦾 **Articulated Robotic Arm**: Multi-axis manipulator with high-precision feedback servos and interchangeable end-effector claw.
- 🧠 **On-Device Edge AI Vision**: Real-time target recognition, obstacle classification, and autonomous pathfinding without external cloud dependencies.
- 📡 **Real-Time Telemetry & Safety**: Dual ultrasonic array, IMU tilt stabilization, live camera streaming, and failsafe auto-stop.
- 💡 **Aesthetic & Functional Illumination**: Dual-tier chassis with 360° perimeter status LEDs for low-visibility operations.

## 🚀 Key Technical Specifications

| Subsystem | Specification |
| :--- | :--- |
| **Chassis** | High-durability multi-layer deck with integrated cable ducting & LED aura |
| **Mobility** | 6-Wheel / Multi-drive high-traction off-road tires with geared DC motors |
| **Robotic Arm** | Multi-DOF articulated arm with dual-jaw gripper end-effector |
| **Sensors** | Dual ultrasonic rangefinders (front), elevated wide-angle camera mast, IMU |
| **Edge Processor** | Embedded micro-edge AI vision board for real-time inference |
| **Power Distribution** | Modular high-discharge LiPo battery with regulated step-down converters |
| **Control Modes** | Fully Autonomous (AI-guided) / Semi-Autonomous / Manual RF Teleoperation |

## 🎯 Target Applications

1. **Planetary Exploration & Mars Rover Analogs**: Collecting surface soil/mineral samples in remote desert zones.
2. **Search and Rescue (SAR)**: Navigating disaster areas, assessing hazardous structures, and relaying live situational data.
3. **Hazardous Environment Inspection**: Performing remote inspections in industrial, chemical, or electrical environments.
4. **Sample Retrieval & Manipulation**: Grasping, lifting, and transporting objects safely without human intervention.
